# Container

Aplicação principal responsável por integrar os microfrontends do restaurante.

## Tecnologias

- React
- Next.js
- JavaScript
- Webpack
- Module Federation

## Funcionalidades

- Integra o Micro Catálogo.
- Integra o Micro Pedido.
- Exibe os microfrontends em uma única aplicação.
- Permite a comunicação entre os micros através de eventos globais.

## Como executar

Instale as dependências:

```bash
npm install

Inicie a aplicação:

```bash
npm run dev
