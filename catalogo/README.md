# Micro Catálogo

Microfrontend responsável por exibir os pratos disponíveis no restaurante.

## Tecnologias

- React
- Next.js
- JavaScript
- Webpack
- Module Federation

## Funcionalidades

- Exibe uma lista de pratos.
- Mostra o nome e a descrição de cada prato.
- Possui um botão para adicionar o prato ao pedido.
- Envia o prato selecionado para os outros micros através de um evento global.

## Como executar

Instale as dependências:

```bash
npm install

Inicie a aplicação:

```bash
npm run dev
