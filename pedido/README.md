# Micro Pedido

Microfrontend responsável por exibir os pratos adicionados ao pedido.

## Tecnologias

- React
- Next.js
- JavaScript
- Webpack
- Module Federation

## Funcionalidades

- Exibe os pratos adicionados ao pedido.
- Mostra o nome e a descrição de cada prato.
- Recebe os pratos selecionados através de um evento global.
- Atualiza a lista de pedidos conforme novos pratos são adicionados.

## Como executar

Instale as dependências:

```bash
npm install

Inicie a aplicação:

```bash
npm run dev
